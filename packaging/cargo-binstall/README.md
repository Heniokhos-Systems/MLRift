# cargo-binstall

MLRift is **not** a Rust crate and is not published on crates.io.
`cargo-binstall` does not apply to this project.

## Installing MLRift

Use one of the following methods:

### Shell installer (Linux / macOS / Android)
```sh
curl -sSf https://raw.githubusercontent.com/Heniokhos-Systems/MLRift/main/install.sh | sh
```

### PowerShell (Windows)
```powershell
irm https://raw.githubusercontent.com/Heniokhos-Systems/MLRift/main/install.ps1 | iex
```

### Homebrew (macOS / Linux)
```sh
brew install mlrift
```

### Scoop (Windows)
```powershell
scoop bucket add mlrift https://github.com/Heniokhos-Systems/MLRift
scoop install mlrift
```

### AUR (Arch Linux)
```sh
yay -S mlrift
```

### Winget (Windows)
```powershell
winget install Pantelis23.MLRift
```

### Manual download
Prebuilt binaries for all platforms are available at:
https://github.com/Heniokhos-Systems/MLRift/releases
